## Step 2: Upload files

Upload the two source documents for this site:

- **Asset Workbook** (`.xlsm`) — reads the `New_Equipment` sheet.
- **Camera Chart** (`.xlsm`) — reads the `Cam Chart` sheet.

You can upload either one independently — you don't need both to
proceed. Each preview shows what was parsed *before* anything is saved;
review it, then click that file's **Save** button.

If the file's Location Code doesn't match the site you picked in Step 1,
you'll see a warning — double check you have the right file for the
right site before saving.

Saving is safe to repeat: it's keyed by (site, camera number) for the
Camera Chart and (site, serial number) for the Asset Workbook, so
re-uploading a corrected file overwrites just the matching rows.
