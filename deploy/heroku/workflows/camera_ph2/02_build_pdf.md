## Step 2 — Build a PDF from the cleaned images

Take the ZIP you downloaded from Step 1 and turn it into a multi-page PDF
grid.

**What to do:**

1. Upload the ZIP from Step 1 (you can drop multiple if you have several
   sites).
2. Open **⚙️ Settings** if you want to change columns, page size, or
   thumbnail quality. Defaults match the existing `camera_views.pdf`
   layout.
3. Click **📄 Build PDF** on each tab.
4. Click **⬇️ Download PDF** for each one (or **⬇️ Download all** if you
   built more than one).

**Hand-off to the next step:** keep the downloaded PDF — Step 3 will sign it.
